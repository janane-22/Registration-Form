# Registration-Form
This project is a responsive student registration form built using HTML, CSS, and JavaScript. It allows users to enter details such as name, age, email, password, gender, and course selection, then displays the submitted data in a dynamic student table. The form includes client-side validation, showing an alert if any required field is empty.​

## Features
Clean, user-friendly registration form interface

Fields for Name, Age, Email, Password, Gender, and Course selection

“Save” button to submit form data

Real-time client-side validation for empty fields

Data displayed in a student table below the form

Passwords masked in the table display for privacy

Option to delete entries from the student table

Responsive layout styled with modern CSS

## Technologies Used
HTML for structure

CSS for styling and responsive design

JavaScript for form logic, validation, table updates, and delete functionality
